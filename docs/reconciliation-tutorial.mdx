This tutorial walks through a monthly bank reconciliation using a Grok Bot agent. Prefer **Reconcile Bank Statement** (Import → Categorise → Match invoices → Find Unpaid Invoices in one go). You can still run **Import bank CSV**, **Categorise bank data**, **Match invoices**, and **Find Unpaid Invoices** separately.

<Info>
 The agent will (via Reconcile Bank Statement or the steps below):

1. **Import** — prepare the month's Google Drive folder and Google Sheet, paste the bank CSV into the raw import columns only
2. **Categorise** — fill Date, Counterparty, Category, Credit, and Debit; seed Categories and Counterparty reference tabs; verify totals
3. **Match invoices** — match expense invoices (received) and revenue invoices (sent) — Unfiled Drive folders first, then email, then manual chat uploads; set each Bank row's **Source** (`Drive`, `Email`, or `Manual`); fill Summary; save links in the month Expenses and Revenue folders
4. **Find Unpaid Invoices** — fill Summary Unpaid Expense / Unpaid Revenue tables from inbox and Sent (or test fixtures)
</Info>

## Export your monthly bank statement

All banks should have an option to export bank transactions. 

- Export last month's bank statement as a CSV and save the file to your computer.

The skill maps common bank CSV layouts, so the agent can import statements even when column names vary by bank.

<Info>
  A **CSV** (Comma-Separated Values) file is a plain-text spreadsheet: each row is a transaction, and columns such as date, amount, and description are separated by commas. Banks use CSV so you can open the statement in Sheets or Excel and so the agent can import the data into your reconciliation workbook.
</Info>

<Tip>
  Automating monthly bank pulls is possible later, but only with tightly restricted access. For this tutorial, export a CSV by hand — simpler and safer.
</Tip>

## Prepare the month's folder and sheet

<Steps>
  <Step title="Create year and month folders">
    Under your Drive Accounts root (`{drive.root_path}/{drive.accounts_folder}`), ensure the year folder exists for the statement year, including an extracts subfolder. Then create the month folder for the statement month (`YYYYMM`) if it is missing.
  </Step>
  <Step title="Locate the bank CSV">
    Look for the CSV under `root / Accounts / year / extracts / month`. If it is missing, obtain it from the operator and save it into that folder before importing.
  </Step>
  <Step title="Copy the versioned template, then copy lookups from last month">
    For a **new** month sheet, Drive-copy the shared Google Sheet from the version-named folder in `config/product.yaml` (`templates.reconciliation_sheet_version` must match the folder name; folder id `templates.reconciliation_version_folder_id`; Sheet pin `templates.reconciliation_sheet_id` / `templates.reconciliation_sheet_url`). Rename the copy from the sheet title pattern. The template is already a native Google Sheet (no `.xlsx` upload). Do not create a blank spreadsheet or edit the source template. Do not copy the entire previous month workbook.

    If a previous month's sheet exists, copy **data rows only** into the new workbook for: `Categories`, `Counterparties`, `Counterparty-Match`, `Counterparty-Category`, and `Email matching`. Keep template headers/layout. Do not copy Bank / raw CSV / Summary / Config from last month. Never edit last month's sheet in place.

    If this month's sheet already exists (re-import), open it and clear/replace the raw CSV area; keep reference tabs.
  </Step>
</Steps>

## Inspect the layout

Before writing, confirm tab names and column headers. Tabs usually include:

- Transactions tab (main reconciliation grid)
- `Categories` — allowed category spellings plus **Type** (`Expense` or `Revenue`)
- `Counterparty-Match` — formatted name ↔ raw bank name
- `Counterparties` — unique formatted names plus Email, Phone, Registration, Address
- `Counterparty-Category` — formatted name ↔ category
- `Email matching` — Gmail search rules per counterparty

On the transactions tab, locate columns by header name. Typical layout:

`Date | Counterparty | Category | Credit | Debit | VAT | Ref | Invoice | Notes | Source` then the raw CSV area to the right (often starting at column K).

`Ref` is the invoice reference number. `Invoice` holds the Drive file link. Do not rename `Ref` to `Invoice`.

## Import the CSV

Paste the CSV into the first empty column to the right of the reconciliation columns (often starting at column K). If the template already has raw CSV headers there, keep them and write data from row 2; otherwise put headers in row 1 and data from row 2. Write numbers as numbers and dates as real dates.

**Import stops here** — do not fill Date, Counterparty, Category, Credit, or Debit in this skill. Then run **Categorise bank data**.

## Run Categorise bank data

## Fill the reconciliation columns

Create one reconciliation row per CSV row.

| Column | How to fill it |
| --- | --- |
| **Date** | Transaction date as a real date, display format `d-mmm` (for example `5-Nov`) |
| **Counterparty** | Prefer Merchant, else Payee Name, else Payer Name, else Description. Loose-match against `Counterparty-Match`. If no match, write a clean, properly cased name. For credits, use the paying client from the bank string |
| **Category** | Look up the formatted name in `Counterparty-Category`. Otherwise pick from `Categories`. If those tabs have no data rows yet (first month), invent a short consistent category — do not leave Category blank |
| **Credit** | Absolute amount if money came in; otherwise blank |
| **Debit** | Absolute amount if money went out; otherwise blank |
| **VAT** / **Ref** / **Invoice** / **Notes** | Leave blank on this pass; fill when matching invoices |
| **Source** | Leave blank on this pass; set when matching (`Email`, `Manual`, or `Drive`) |

Clear any leftover formulas or junk below the last data row.

## Seed reference tabs

In the same run, after filling Bank, seed (or extend) the reference tabs from those rows and the raw bank string for each counterparty:

- `Categories` — unique Category values from Bank
- `Counterparty-Match` — formatted `Counterparty` ↔ raw `Match` string
- `Counterparties` — unique formatted names (column A); contact columns filled later from invoices
- `Counterparty-Category` — formatted name ↔ Category used on Bank

Skip keys that already exist (later months). Do not unhide the tabs unless the operator asks.

## Verify and report

- Row count should match the CSV
- Dates should display as `d-mmm`
- `SUM(Credit)` and `SUM(Debit)` should match the CSV totals in and out
- The four reference tabs above should have data rows consistent with Bank (not header-only after a first fill)

Report the sheet link, totals, category counts, that reference tabs were seeded or updated, and any guesses (new counterparties or unsure categories).

## After review

When the operator says they have finished editing Category or Counterparty names (or other sheet changes), run **Sync spreadsheet mappings**. That skill clarifies rename vs new category/counterparty, updates the reference tabs, and refreshes Summary missing-invoice lists and highlights.

## Run Match invoices

## Match expense invoices (debits)

Run this when the operator asks to match invoices to bank rows.

**Source** on the Bank row records how the invoice was found:

| Source | Meaning |
| --- | --- |
| `Drive` | Found under Unfiled expense invoices and moved into the month Expenses folder |
| `Email` | Found in Gmail (or test-session `.eml` fixtures) |
| `Manual` | Operator uploaded the file into the agent chat |

Search order: **Unfiled → email → Manual** (Manual only after the unmatched report, when the operator uploads).

Unfiled expense invoices live at `Drive root / Accounts / Unfiled / Expense Invoices` (profile: `{drive.root_path}/{drive.accounts_folder}/{drive.unfiled_folder}/{drive.unfiled_expense_invoices}`).

<Steps>
  <Step title="Check Unfiled expense invoices">
    For each debit row, search the Unfiled expense invoices folder first. On a match, **move** the PDF into the month Expenses folder (rename to `YYYYMMDD_Counterparty_Ref.pdf` if needed — `Ref` is the invoice reference number, e.g. `20261115_Acme_INV78.pdf`), set Invoice / VAT / Ref as usual, and set **Source = `Drive`**. Do not add an `Email matching` rule solely for a Drive match.
  </Step>
  <Step title="Search with Email matching rules">
    If Unfiled has no match, check `Email matching`. If the counterparty is listed, search Gmail with that rule, narrowed by date and amount.
  </Step>
  <Step title="Fall back to a general search">
    Otherwise search by counterparty name, raw merchant text, a window of about two weeks before to a few days after the bank date, and the amount (include original FX amounts from the raw CSV when relevant).
  </Step>
  <Step title="Attach an email-matched invoice">
    Prefer a PDF attachment. Upload to an expenses subfolder inside the spreadsheet's folder as `YYYYMMDD_Counterparty_Ref.pdf` (`Ref` = invoice reference number, e.g. `20261115_Acme_INV78.pdf`). Put a Drive hyperlink in **Invoice** whose **visible label is that filename** (not the raw URL), and format **Invoice** with **Clip** overflow (not Wrap). Fill **VAT** (tax amount) and **Ref** (invoice number) from the invoice when present. Set **Source = `Email`**. Add **Notes** only when something needs attention (FX/VAT mismatch, multi-charge invoice, uncertain match, and similar).

    Update `Counterparties` Email, Phone, Registration, and Address from the invoice. Prefer a finance / billing / accounts email when several appear. If those values changed versus what was already on the sheet, overwrite them and tell the operator what changed.

    Immediately save or update the working Gmail rule in `Email matching`. Skip rows that need no invoice: Categories with Invoice Required unchecked, plus bank-fee and Personal / Personal expense fallbacks — unless an invoice is already linked. Never send, reply to, or change emails.
  </Step>
</Steps>

Report the expenses folder link, matches found (with Source counts), notes written, contact updates, and debit rows still missing an invoice. When the operator uploads a missing file in chat, file it under Expenses and set **Source = `Manual`**.

## Match revenue invoices (credits)

For credit rows (money in from clients), match invoices the company sent.

Unfiled revenue invoices live at `Drive root / Accounts / Unfiled / Revenue Invoices` (profile: `{drive.root_path}/{drive.accounts_folder}/{drive.unfiled_folder}/{drive.unfiled_revenue_invoices}`).

<Steps>
  <Step title="Check the Revenue folder">
    Create a revenue subfolder inside the spreadsheet's folder if needed. Look there first for an existing matching PDF. If linking an already-filed file and Source is empty, leave Source blank.
  </Step>
  <Step title="Check Unfiled revenue invoices">
    Otherwise search Unfiled revenue invoices. On a match, **move** the PDF into the month Revenue folder, rename to `YYYYMMDD_Counterparty_Ref.pdf` if needed (`Ref` = invoice reference number), and set **Source = `Drive`**.
  </Step>
  <Step title="Search Gmail Sent">
    Otherwise search Sent mail for outbound invoices to that client (name, amount, similar date window). When a bookkeeping test session is active, use the sample sent `.eml` fixtures instead of Gmail.
  </Step>
  <Step title="Attach an email-matched outbound invoice">
    Upload to the revenue folder as `YYYYMMDD_Counterparty_Ref.pdf` (`Ref` = invoice reference number, e.g. `20261115_Acme_INV78.pdf`). Set the **Invoice** hyperlink (filename label, Clip overflow), fill **VAT** / **Ref** when present, and set **Source = `Email`**. Update client contact fields on `Counterparties` from the invoice when available; tell the operator if values changed. The Bank **Counterparty** remains the paying client from the bank CSV — seed that name on `Counterparties` if it is new.
  </Step>
</Steps>

Report the revenue folder link, credit matches (with Source counts), and credit rows still missing an invoice. Manual chat uploads set **Source = `Manual`**.

## Fill the Summary tab

After invoice matching, fill **Summary** (Match invoices skill):

- **Keep blocks; clear data when empty** for every Summary table: never delete title/headers (or the Expenses by Category pie) when there are no data rows — clear data under the headers only. Leave empty Unpaid shells intact for Find Unpaid Invoices.
- **Missing Expense Invoices** / **Missing Revenue Invoices** — live formulas over the transactions tab (Debit/Credit with blank Invoice). **Insert sheet rows** under a table header before writing a spill so lower titles (for example Missing Revenue under Missing Expense) are never overwritten. On **Bank Transactions**, highlight those same missing-invoice rows in light red so they match the Summary tables. Exclude Categories with **Invoice Required** unchecked (and bank-fee / Personal fallbacks); those rows stay unhighlighted. Both missing tables may include **No Invoice Needed** (sets Invoice Required false for that row’s Category). Missing Expense may also include **Personal Expense** (sets Category to Personal and ticks No Invoice Needed).
- **Expenses by Category** — Category labels from expense-typed rows on `Categories` (**Type** = Expense). **Total** cells use formulas that sum **Debit** on the transactions tab by Category (for example `SUMIF`), so changing a bank row’s Category updates the table and the linked pie chart. **Percentage** is formula-driven over those Totals (`0%` display).
- Create or update **one** pie chart bound to Category + Total (spare rows under the table; no duplicate charts on reruns; do not delete the pie when the category table is empty).

## Hand back

If any invoices are still missing:

1. List them in chat (Date, Counterparty, amount), expenses vs revenue.
2. Point the operator to the same lists on the **Summary** tab (**Missing Expense Invoices** / **Missing Revenue Invoices**); matching Bank Transactions rows are light red.
3. Ask them to either drop the PDFs into the chat, or upload them to Unfiled Expense Invoices / Unfiled Revenue Invoices under Accounts.
4. When they have done that, re-run **Match invoices** on the **same** spreadsheet (Unfiled → Source=`Drive`; chat upload → Source=`Manual`). **Update Summary** so newly matched rows leave the Missing Expense / Missing Revenue data rows (keep the table blocks; clear data when empty), clear light-red highlights on those Bank rows, and hand back again.

Also tell the operator they may update Category names, Category Type, or Counterparty names directly on the spreadsheet. When they are finished, they should let the agent know (or ask to **Sync spreadsheet mappings**) so mappings and Summary stay consistent. Re-run **Match invoices** when they have new invoice files to attach.
